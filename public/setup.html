JOBBER

First-run setup · all local, nothing leaves your machine

unconfigured

Jobber talks to a local Ollama server; no cloud models are ever used. If you haven't installed Ollama yet, grab it from ollama.com, start it, then continue below.

1 Connect to Ollama

Default: http://localhost:11434 — this is only correct when Ollama runs on the very same machine.

If Ollama lives on another machine (e.g. the Windows host while you're in WSL), point the URL there instead: http://<that-ip>:11434

How to find the address: ip route | grep default · ipconfig (Windows) · ip addr / ifconfig (Linux / macOS)

2 Assign models

Jobber never downloads anything — you install the models yourself first, e.g. ollama pull qwen3.5:4b. Below you'll pick which installed model handles each role; nothing is pre-selected for you.

Extraction — an instruction-tuned model that turns raw text into structured facts. Recent Qwen variants are a safe bet.
Reasoning — needs strong reasoning and instruction-following for matching and tailoring. Recent Phi or Qwen variants.
Validation — judges the final claims. Reusing your extraction model usually works fine.

In general, higher parameter counts give sharper results but need proportionally more VRAM. The recommended picks (≈4B) run comfortably on ~6 GB VRAM; only go bigger if your GPU allows.

3 Finish

Configuration saved
